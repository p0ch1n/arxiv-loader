1.2 異常偵測框架：從傳統到 LLM 整合

純 LLM 並非萬能——最佳方案是傳統異常偵測 + LLM 描述生成的兩階段架構：

Stage 1：高效異常定位（傳統方法）

🎯
AnomalyCLIP NEW
利用 CLIP 的 text-image 對齊能力做 zero-shot 異常偵測。輸入文字描述「正常外觀」即可偵測偏差，無需額外訓練。適合初期缺乏標注資料的場景。
🪟
WinCLIP / WinCLIP+
滑動視窗 + CLIP 的 zero/few-shot 工業異常偵測，2023–2024 年 MVTec 榜首。Few-shot 只需 1–4 張正常樣本即可啟動。
🔍
PatchCore
Memory bank + 近鄰搜尋，無需訓練，推理時直接比對特徵距離。工業界最廣泛部署的基線方法，速度快、解釋性好。
🌀
RealNet / UniFormaly
2024–2025 新方法，統一架構同時支援 texture / structural 異常，單一模型覆蓋多品類缺陷。

Stage 2：LLM 深度描述與根因分析

將 Stage 1 的異常 mask / bounding box 作為視覺 prompt 送入 LLM，要求模型：

  • 描述異常的位置、形態、嚴重程度
  • 比對已知缺陷類型資料庫，給出缺陷類別推測
  • 生成自然語言報告供人工審查
  • 評估誤報可能性（模型不確定性）

⚠️ 為何不直接用 LLM 做 Stage 1？

LLM 視覺理解的定位精度（pixel-level）遠不如專用異常偵測模型；且 LLM 推理成本高（每次推理 0.5–5 秒），無法負擔全量影幀掃描。正確策略是：Stage 1 快速篩選可疑幀（毫秒級）→ Stage 2 深度分析（秒級）。

電子束 × 光學跨模態學習
與雜訊標籤處理

以電子束相機（EB，512×512）的標記作為光學相機（32×32）的監督信號，在奈米尺度下訓練缺陷偵測模型。這是一個同時涉及跨模態域遷移、解析度鴻溝、物理不可見性標籤的複合難題。

2.1 問題精確定義

⚠️ 核心問題：EB 可見缺陷 ⊃ 光學可見缺陷
EB 標記的部分缺陷在 32×32 光學圖中根本無法被感知
🔬 物理根因：這不是普通的雜訊標籤

光學繞射極限約 200–400nm。對於 10nm 以下的特徵，32×32 像素的光學圖在空間頻域上根本無法編碼對應的缺陷資訊。這類標籤不是「錯誤標注」，而是「物理不可見標籤」——它的存在對光學模型是真實的雜訊。

但這不代表模型無法學習：光學圖中可能存在缺陷的間接相關特徵（周邊材質應力、整體圖案形變等），模型可學習這些代理特徵（proxy features）。

雜訊類型分類

雜訊類型成因佔比估計處理策略
物理不可見標籤 缺陷尺寸 < 光學解析度極限 20–50% 實例重加權 / 樣本剔除
配準誤差雜訊 EB↔光學座標對齊不完美 5–15% 軟標籤 / 空間模糊化
EB 誤標注 EB 自身的假陽性 1–5% Confident Learning 識別
跨模態域偏移 兩台相機材質對比度差異 全域影響 跨模態域適應

2.2 雜訊標籤學習方法

大型訓練集 + 雜訊標籤的核心挑戰：模型會記憶雜訊（memorization effect）。2024–2026 年最有效的方法：

🧹
Confident Learning cleanlab
估計每個樣本的「標籤正確機率」，識別出高置信度的雜訊樣本。cleanlab 庫已有完整 PyTorch 整合。

優勢：不需改架構，直接對現有資料集做清洗；對物理不可見標籤有較好識別能力（模型損失持續高的樣本）。
離線清洗
🤝
DivideMix ICLR 2020
將訓練集動態分為「乾淨」和「雜訊」兩組，混合使用監督 + 半監督訓練。雜訊樣本以 soft pseudo-label 參與訓練而非丟棄。

優勢：雜訊率達 80% 仍有效；特別適合本場景中大比例物理不可見標籤。
訓練時動態
📊
CORES² / SOP
Self-paced co-training：兩個獨立網路互相監督，僅在雙方一致時才更新標籤。

優勢：計算成本低於 DivideMix，適合訓練資源受限的場景。
輕量共訓練
🎓
Curriculum Learning
先用高置信度（低損失）樣本訓練，逐步加入困難 / 不確定樣本。

在本場景的意義：先用 EB 可見且光學也可能可見的大缺陷訓練，再逐步加入小缺陷標籤，讓模型先建立穩健的特徵基礎。
訓練策略
🏷️
Label Smoothing + Soft Labels
不要使用 hard 0/1 標籤。根據缺陷尺寸相對於光學解析度的比值，計算「可見機率」作為 soft label。

例：缺陷 5nm，光學極限 200nm → 可見機率 ≈ 0.1，標籤為 0.1 而非 1.0。
標籤工程
🎲
Mixup + AugMix
對光學圖像做大量資料增強（旋轉、色偏、高斯噪聲、CutMix），使模型對圖像擾動更健壯，間接降低雜訊標籤的影響。與其他方法組合使用效果最佳。
增強正則
💡 針對「物理不可見標籤」的特殊處理

傳統雜訊標籤方法假設雜訊是隨機的；本場景的雜訊是系統性的（小缺陷 = 高雜訊）。建議：

  • 1. 用 EB 圖計算每個缺陷的實際尺寸，轉換為「光學可見機率」
  • 2. 以此機率作為 instance weight 或 soft label
  • 3. 尺寸 < 某閾值的樣本直接從訓練集移除（或降權至 0.05 以下）

2.3 跨模態知識蒸餾策略

核心思路：讓 EB 訓練的教師模型（高品質）引導光學學生模型（低解析度）學習有意義的特徵。

▌ 跨模態蒸餾架構
EB 圖 (512×512)
→
EB Teacher Encoder
(CNN / ViT，凍結)
→
Teacher Features
Z_T ∈ ℝ^d
↕ 對齊損失 L_align = ‖Z_S − proj(Z_T)‖²
光學圖 (32×32)
→
Optical Student Encoder
(輕量 CNN，可訓練)
→
Student Features
Z_S ∈ ℝ^d
總損失 = L_task（分類）+ λ₁ · L_align（特徵蒸餾）+ λ₂ · L_contrast（跨模態對比）

具體實作：三種蒸餾目標

📐
Feature Alignment（特徵對齊）
在共享嵌入空間中，要求同一元件的 EB 特徵與光學特徵接近。使用 projection head 橋接維度差異。

損失：MSE(Z_S, proj(Z_T.detach()))
🔗
Contrastive Cross-Modal
正樣本對：同一元件的 EB + 光學圖。
負樣本對：不同元件。
使用 InfoNCE loss（類似 CLIP）學習模態不變表示。
🎭
Soft Prediction Distillation
教師模型的 logit 分佈（softmax 前）作為學生的監督目標，比 hard label 包含更多「排名資訊」，在雜訊場景下更穩健。

損失：KL(p_S ‖ p_T)

EB-to-Optical 影像翻譯（輔助工具）

訓練一個 Pix2Pix / CycleGAN，將 EB 圖降解析度翻譯為模擬光學圖。用途：

  • 可見性預測：觀察翻譯後圖像中缺陷是否仍可見，自動計算「可見機率」
  • 資料增強：EB 圖翻譯後增加光學訓練樣本數量
  • 教師輔助：教師模型同時在 EB 和模擬光學圖上訓練，學生更好對齊
✅ 關鍵洞察：學習「代理特徵」

即使缺陷在 32×32 光學圖中不可直接觀察，訓練資料量足夠大時，模型可學習統計代理信號：

  • 缺陷周圍的整體圖案形變或對稱性破壞
  • 特定位置的局部亮度分佈異常
  • 鄰近結構的幾何偏差

這些代理特徵在 32×32 解析度下是存在的，只是需要大量樣本讓模型發現規律。這正是大訓練集的價值所在。

    labels=labels,
    pred_probs=pred_probs,
    return_indices_ranked_by="self_confidence",
    filter_by="prune_by_noise_rate",

# 計算缺陷可見機率（基於 EB 物理尺寸）
def visibility_prob(defect_size_nm, optical_resolution_nm=160):
    """sigmoid 型可見性模型"""
    ratio = defect_size_nm / optical_resolution_nm
    return float(1 / (1 + np.exp(-5 * (ratio - 0.5))))

# 建立 soft label
soft_labels = np.array([
    visibility_prob(size) if label == 1 else 1 - visibility_prob(size) * 0.1
    for size, label in zip(defect_sizes_nm, labels)
])

Phase 3：跨模態蒸餾訓練迴圈

class CrossModalDistillLoss(nn.Module):
    def __init__(self, alpha=0.5, beta=0.3, temperature=4.0):
        super().__init__()
        self.alpha = alpha   # feature alignment weight
        self.beta = beta     # soft prediction weight
        self.T = temperature

    def forward(self, student_feat, teacher_feat,
                student_logits, teacher_logits, soft_labels):
        # 1. 任務損失（Soft Label BCE）
        task_loss = F.binary_cross_entropy(
            student_logits.sigmoid(), soft_labels
        )
        # 2. 特徵對齊損失
        align_loss = F.mse_loss(student_feat, teacher_feat.detach())

        # 3. Soft prediction KD
        soft_student = F.log_softmax(student_logits / self.T, dim=-1)
        soft_teacher = F.softmax(teacher_logits.detach() / self.T, dim=-1)
        kd_loss = F.kl_div(soft_student, soft_teacher, reduction='batchmean')
        kd_loss *= self.T ** 2

        return task_loss + self.alpha * align_loss + self.beta * kd_loss

角色推薦架構輸入理由
EB 教師 ResNet-50 / ViT-S 512×512 高解析度特徵提取，預訓練 ImageNet 權重可直接 fine-tune
光學學生 MobileNetV4 / EfficientNet-B0 32×32 32×32 輸入非常輕量，參數量控制在 1–3M 即可
Projection Head 2-layer MLP — 橋接師生特徵維度差異
GAN 翻譯器 Pix2Pix (UNet) 512×512→32×32 輔助生成模擬光學圖，用於可見性估計
📌 大訓練集 + 高雜訊率的最佳實踐
  • 不要一次性全量訓練：先用 Confident Learning 清出高置信度子集（約 30–50%），在此子集上做初步訓練建立 warm start
  • 動態 hard negative mining：訓練中監控每個樣本的損失，損失持續偏高的很可能是雜訊或困難樣本，可動態降低其 weight
  • Exponential Moving Average（EMA）：維護模型的 EMA 版本，雜訊場景下 EMA 模型穩定性顯著優於即時模型
  • 驗證集必須用 EB 標記重新確認：測試集只用 EB 可直接確認為可見的缺陷，確保評估指標的可靠性

進階：Self-Supervised Pre-training 降低雜訊依賴

在送入監督訓練之前，用光學圖像做自監督預訓練（不需標籤），讓模型學習通用的光學域特徵表示。推薦方法：

  • DINO / DINOv2：自蒸餾 ViT，特別適合無標籤的工業圖像
  • MAE（Masked Autoencoder）：在 32×32 圖上做 patch masking，學習重建，適合紋理豐富的半導體圖像
  • SimCLR：對比學習，同一元件不同裁剪作為正樣本對

自監督預訓練後，模型對雜訊標籤的抵抗力顯著提升（已有良好特徵基礎，不需靠標籤來學習表示）。

核心結論

🤖
Part 1 要點
2026 年最佳策略：Stage 1 PatchCore / AnomalyCLIP 快速篩選 + Stage 2 Qwen2.5-VL-7B AWQ 深度描述。不要直接用 LLM 做 pixel-level 偵測，成本過高且精度不足。
⚗️
Part 2 要點
物理不可見標籤 ≠ 普通雜訊，需要可見性 Soft Label 而非直接剔除。跨模態蒸餾 + DivideMix + 自監督預訓練的組合在大規模雜訊資料集上效果最佳。
🔑
最關鍵洞察
光學模型學習的是「統計代理特徵」而非缺陷本身——這在物理上合理且可行，需要大量訓練資料讓模型發現這些隱性規律。驗證集必須排除物理不可見樣本才能評估真實效能。
